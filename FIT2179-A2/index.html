When Rain Becomes Risk

This visualisation explores Malaysia’s precipitation patterns and how heavier rainfall connects to flood-related disaster risk. It focuses on where rainfall is highest, when rainfall is most intense, and how flood disasters appear across time.

This project explores a relationship, not direct causation. Flood impacts are also affected by drainage, land use, urbanisation, river systems, and population exposure.

1. Rainfall is not evenly distributed across Malaysia

These maps show different ways of understanding rainfall across Malaysian states.

2. Which states are wetter?

These charts compare rainfall levels directly between Malaysian state codes.

3. Rainfall changes by month

Monthly rainfall patterns show when rainfall tends to be stronger.

4. Rainfall matters because floods dominate the disaster story

The disaster charts show why rainfall is important for understanding risk in Malaysia.

Author: Faraz Rasool. Created for FIT2179 Data Visualisation 2, 2026. Visualisations created using Vega-Lite. Data sources: rainfall and natural disaster datasets.
